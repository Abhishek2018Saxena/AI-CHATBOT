# AI-Chatbot

## Description
This project is a simple AI chatbot developed using Python and Flask. 
The chatbot interacts with users through a web interface and gives automatic responses.

## Objective
The objective of this project is to build a chatbot that can communicate with users and answer simple questions.

## Technologies Used
- Python
- Flask
- HTML

## Working of the Chatbot
The chatbot uses conditional statements in Python such as:
- if
- elif
- else

These statements check the user's input and return the correct response.

Example:
If the user types "hello", the chatbot replies "Hi! How can I help you?"

## How to Run
1. Open Command Prompt
2. Go to the project folder
3. Run:

python app.py

4. Open browser and go to:
http://127.0.0.1:5000
